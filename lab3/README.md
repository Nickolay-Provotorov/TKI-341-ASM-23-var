## Лабораторная работа №3. Команды передачи управления

### Цель работы
Изучение команд передачи управления и получение навыка работы с ними.

### Постановка задачи
1. С помощью процедуры Random сформировать случайное целое число в диапазоне от 0 до 65535.
2. Распределить числа по массиву data:
   * Четное число записать в ячейку памяти, начиная с нулевого элемента массива data (0–127).
   * Нечетное число записать в ячейку памяти, начиная с 128 элемента массива data (128–255).
   * Все числа, которые больше или равны 50000, записать в ячейку памяти, начиная с 256 элемента массива data (256–383).
   * Все числа, которые меньше 10000, записать в ячейку памяти, начиная с 384 элемента массива data (384–511).
3. Повторять п.1–п.2, пока число распределенных данных по любому из признаков не превысит 127.
