Занести следующие числа в память:
| Переменная | Значение   |
| ---------- | ---------- |
| a          | 5 678 901  |
| b          | 6 789 012  |
| c          | 7 890 123  |
| d          | 8 901 234  |
| e          | 9 012 345  |
| f          | 10 123 456 |

Вычислить выражение для варианта 23 (целочисленное деление):
(4a-b-1)/((c/b)+a)
Результат записать в память и вывести дамп памяти.
